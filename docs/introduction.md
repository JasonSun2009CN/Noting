# Noting 简介

Noting 是一个可以自己部署的笔记与知识库工具。它用起来像 Notion —— 块编辑器、无限层级的页面、数据库视图、全文搜索 —— 但所有内容都保存在你自己的服务器上，是一个你可以随时打包带走的 SQLite 文件。

如果你喜欢 Notion 的写作体验，却不想把笔记交给第三方，Noting 是为你准备的。

## 它适合谁

- **在意数据归属的人**：笔记、图片、数据库都在 `data/` 目录里，备份就是复制一个文件夹。
- **想在自己服务器或 NAS 上跑一个知识库的人**：一个 Node 进程 + 一个 SQLite 文件，没有外部依赖。
- **想用 AI 但不想被绑定的人**：自带 API Key，支持 OpenAI、Anthropic、DeepSeek、Ollama 或任何兼容 OpenAI 的接口，随时可换。
- **个人、家庭或小团队**：不需要注册、不需要订阅，也没有用量限制。

## 你能做什么

- **写**：标题、列表、待办、折叠块、引用、提示框、代码块、图片、子页面；支持 Markdown 快捷输入、斜杠菜单和拖拽排序。
- **组织**：无限层级的页面树、收藏、图标与封面，每一页可以单独设置排版。
- **管理信息**：用数据库做表格或看板，自定义属性（文本、数字、单选、多选、勾选、网址、日期），支持排序和行详情。
- **找回来**：全文搜索 + 命令面板，最近页面，误删的页面可以在回收站恢复。
- **问 AI**：在编辑器里用 `⌘J` 唤起 AI 面板，续写、改写或提问；Key 只存在你的浏览器里，不写入数据库、不写日志。
- **导出**：任意页面可一键导出为 Markdown，不被格式锁死。

## 它不是什么

- 不是多人实时协作工具：没有账号体系、评论和实时光标。
- 不是托管服务：没有官方云版本，需要你自己运行。
- 不是移动 App：界面针对桌面浏览器设计，手机浏览器可以使用，但体验未做专门优化。

这些取舍换来的是简单：没有微服务、没有消息队列、没有外部数据库，一台小机器就能跑。

## 五分钟开始

要求 Node.js 20+：

```bash
npm install
npm run dev
```

打开 http://localhost:5173，首次启动会自动创建数据库和一个示例工作区。

正式使用时：

```bash
npm run build
NOTING_PASSWORD='一个足够长的密码' npm start
```

然后用 HTTPS 反向代理（Caddy、nginx 或 Tailscale）暴露到公网。也可以用 Docker：`docker compose up -d --build`。

更详细的配置、备份和快捷键说明见 [README](../README.md)。

## 数据在哪里

```text
data/
├── noting.db        # 页面、块、数据库
└── uploads/         # 页面里上传的图片
```

备份时请先停止服务，或使用 `sqlite3 data/noting.db ".backup 'backup.db'"`，因为 SQLite 运行在 WAL 模式下。
