隐私

这个网站不追踪你。

Noting 是一个本地应用，这个页面也遵循同样的原则。这里没有账号、没有统计分析，也没有 Cookie 弹窗，因为没有需要你同意的东西。

这个网站会保存什么

什么都不保存。页面不设置 Cookie，也不使用本地存储。它不加载任何统计分析、广告或追踪脚本。

服务器日志

本站是由 GitHub Pages 托管的静态文件。GitHub 会收到常规的请求数据，包括你的 IP 地址，并保留自己的日志。这部分适用 GitHub 隐私声明。

版本检查

下载按钮指向 GitHub Releases。为了直接给你对应的安装包，页面加载时会向 GitHub 的公开 API 询问最新版本。这个请求不包含任何笔记内容，也不包含本站生成的标识。如果请求失败，按钮会回到 Releases 页面。

字体

Geist 和 Geist Mono 由本站提供。没有任何字体请求会发给 Google 或其他第三方。

你的笔记

这个页面不会接触你的笔记。Noting 应用把它们保存在你的电脑上。AI 请求从你自己的服务发给你选择的供应商，使用你自己的密钥。README 里有文件位置的说明。

条款

Noting 是基于 Apache 2.0 协议的开源软件，不提供任何担保。完整文本在仓库里。

问题

在 GitHub 上开一个 issue，我们会在那里回复。
