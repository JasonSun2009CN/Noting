Privacy

This site does not track you.

Noting is a local app, and this page follows the same idea. There are no accounts, no analytics and no cookie banner, because there is nothing to consent to.

What this site stores

Nothing. The page sets no cookies and no local storage. It loads no analytics, advertising or tracking scripts.

Server logs

The site is a set of static files hosted by GitHub Pages. GitHub receives the usual request data, including your IP address, and keeps its own logs. That is covered by the GitHub privacy statement.

The release check

The download buttons point at GitHub Releases. To send you straight to the right file, the page asks GitHub's public API for the latest release when it loads. The request contains no note content and no identifier from this site. If it fails, the buttons fall back to the releases page.

Fonts

Geist and Geist Mono are served from this site. No font requests go to Google or any other third party.

Your notes

This page never touches your notes. The Noting app keeps them on your machine. AI requests go from your own server to the provider you choose, using your own key. The README explains where the files live.
